# Security policy

If you find a security problem in Grumpy QR, such as a code that crashes the app, a way to make a link look like it goes somewhere it doesn't, or anything that gets around the "no network" guarantee, please report it privately rather than in a public issue.

**How to report:** use GitHub's private vulnerability reporting: open the [Security tab](https://github.com/nimbice/grumpy-qr/security) and choose **Report a vulnerability**.

Please include the code or image that triggers the problem (or how to produce it), your Android version and device, and what you expected to happen. You'll get a reply as soon as possible. Fixes for real issues are prioritized over everything else.

Only the latest release is supported.
